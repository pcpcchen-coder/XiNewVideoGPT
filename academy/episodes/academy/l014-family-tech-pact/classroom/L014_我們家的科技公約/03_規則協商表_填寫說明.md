# 規則協商表怎麼寫

`03_規則協商表.csv` 可以用 Numbers 或試算表打開，也可以照列印包第 4 頁手寫。

| 欄位 | 寫什麼 |
|---|---|
| 編號、誰提的、主題 | 已經填好：孩子五條、爸爸五條，每個主題各一條 |
| 原本的規則 | 照規則卡抄，不要先改 |
| 說得清楚／做得到／檢查得到 | 過了寫 ✓，沒過寫 ✗ |
| 理由 | 為什麼要這條規則 |
| 沒做到時怎麼補救 | 怎麼補回來，不是處罰 |
| 改成（協商後） | 兩個人都同意的版本 |
| 兩人都同意 | 都同意寫 ✓；沒談好寫「下一版再談」 |

最後一列「自選規則或功能」留給下半場：寫你加了什麼、請爸爸試一次之後保留、修改還是拿掉。
