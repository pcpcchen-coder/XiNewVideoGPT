# EP02《為什麼電腦只懂 0 和 1？》

第二集延續「陳犀牛固定講師」與第一集的十二幕品牌舞台，從電晶體的兩種可靠狀態出發，帶七年級學生用五張卡理解二進位，再把概念遷移到文字編碼、像素與聲音取樣。

## 教學進程

1. 所有數位內容最後都會變成零和一。
2. 為什麼兩種狀態較可靠。
3. 電晶體如何成為微型開關。
4. bit、byte 與兩百五十六種排列。
5. 五張二進位卡與零到三十一。
6. 把十三寫成 `01101`。
7. 位元組與檔案大小單位。
8. 文字編碼與 Unicode。
9. 圖片、像素與顏色數值。
10. 聲音取樣。
11. 所有內容共享同一套底層語言。
12. 情境題與下一集鉤子。
