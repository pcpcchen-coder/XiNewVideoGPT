# EP02 完整製作規格

溝通任務：看完後，七年級學生能解釋電腦選擇二進位的硬體理由，使用五張二進位卡把十三寫成 `01101`，並說明文字、圖片與聲音如何先轉成數值、再轉成位元。

## 敘事順序

疑問鉤子 → 兩態系統的可靠性 → 電晶體 → bit 與 byte → 五張二進位卡 → 十三的轉換 → 檔案單位 → 文字編碼 → 像素 → 聲音取樣 → 共同底層語言 → 情境題收尾。

## 製作規格

- 講師：陳犀牛 Chen XiNew，保留發光犀牛角、工裝背心、名牌與工具包。
- 旁白：全片使用 Microsoft Edge TTS `zh-TW-YunJheNeural`，速率 `-4%`、音高 `-2Hz`。
- 片頭：使用指定 `30Sec.m4a` 來源檔的完整內容（媒體實長 60 秒），搭配陳犀牛品牌蒙太奇，再進入教學內容。
- PPT：十二頁 16:9 可編輯簡報，每頁三句講者備註與 `[Sources]` 來源區塊。
- 視覺：六組本集專屬教學插圖、四種既有陳犀牛透明講師姿勢、深海藍與探索橙品牌舞台。
- 動態：逐幕微推鏡、掃描光與六種輪替轉場；片頭採五段品牌蒙太奇。
- 音樂：片頭使用指定主題曲；教學期間不放背景音樂，只保留旁白。
- 驗收：幕數、旁白、字幕、PPT、片頭、編碼、尺寸、音量與 decode 均須通過自動檢查。
