# EP02 音樂

## 片頭主題曲

`chen-xinew-opening-theme-30sec.m4a` 為使用者指定的《犀牛角亮起來》片頭來源檔，媒體實際長度為 60 秒，來源：

https://github.com/pcpcchen-coder/XiNewIPs/blob/main/assets/%E9%99%B3%E7%8A%80%E7%89%9B%E9%96%8B%E5%A0%B4%E4%B8%BB%E9%A1%8C%E6%9B%B2_%E7%8A%80%E7%89%9B%E8%A7%92%E4%BA%AE%E8%B5%B7%E4%BE%86_30Sec.m4a

原始檔內容為 48 kHz 雙聲道 AAC 音訊；產線會搭配陳犀牛品牌蒙太奇，建立 1920×1080 片頭。

## 教學音訊

投影片講解過程不使用背景音樂，只保留 `zh-TW-YunJheNeural` 旁白。
