# EP02 音樂

## 片頭主題曲

`chen-xinew-opening-theme.mp4` 為使用者指定的《犀牛角亮起來》完整兩分鐘音軌，來源：

https://github.com/pcpcchen-coder/XiNewIPs/blob/main/assets/%E9%99%B3%E7%8A%80%E7%89%9B%E9%96%8B%E5%A0%B4%E4%B8%BB%E9%A1%8C%E6%9B%B2_%E7%8A%80%E7%89%9B%E8%A7%92%E4%BA%AE%E8%B5%B7%E4%BE%86_v0.mp4

原始檔雖使用 `.mp4` 副檔名，實際內容為 48 kHz 雙聲道 AAC 音訊；產線會搭配陳犀牛品牌蒙太奇，建立 1920×1080 片頭。

## 教學背景音樂

`binary-lanterns-loop.wav` 由專案腳本以正弦振盪器、和弦進行與 FFmpeg 效果器程式化產生，不含外部取樣。影片混音時會在旁白出現時自動降低音量。
